# יחידה 7: חיבור עשירוניים

ביחידה הזאת נלמד לחבר מספרים עשירוניים בצורה מסודרת. הסוד החשוב הוא ליישר את הנקודות העשרוניות.

## הסבר

בחיבור עשירוניים כותבים את המספרים אחד מתחת לשני כך שהנקודות נמצאות באותו טור.

אם חסרות ספרות, אפשר להוסיף אפסים בסוף המספר.

דוגמה:

```text
  2.50
+ 1.75
------
  4.25
```

לפני שמחשבים, כדאי לשאול: בערך כמה אמורה להיות התשובה? זה עוזר לבדוק אם לא טעינו.

## דוגמאות פתורות

דוגמה 1:

```text
0.3 + 0.4 = 0.7
```

דוגמה 2:

```text
  4.50
+ 2.25
------
  6.75
```

דוגמה 3:

```text
  1.70
+ 0.08
------
  1.78
```

## פעילות קצרה

בחרי שני מוצרים מהחנות:

- מחברת: `4.50` ש"ח
- עיפרון: `1.20` ש"ח
- מדבקות: `2.75` ש"ח
- מחק: `0.90` ש"ח

חשבי כמה הם עולים יחד. אחר כך בחרי שלושה מוצרים וחשבי שוב.

## תרגול עצמי

1. פתרי: `0.3 + 0.4`, `1.2 + 2.5`, `3.1 + 0.8`.
2. פתרי בטור: `2.35 + 1.40`, `0.75 + 0.60`, `5.08 + 2.12`.
3. הוסיפי אפסים ופתרי: `4.5 + 2.35`, `1.7 + 0.08`.
4. בעיה: מחברת עולה `4.50` ש"ח ועיפרון עולה `1.20` ש"ח. כמה הם עולים יחד?
5. כתבי תרגיל חיבור עשירוני משלך ופתרי אותו.

## מה חשוב לזכור?

- מיישרים נקודה מתחת לנקודה.
- אפשר להוסיף אפסים בסוף כדי לעזור לעצמנו.
- כדאי לבדוק באומדן אם התשובה הגיונית.
