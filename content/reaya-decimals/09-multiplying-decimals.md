# יחידה 9: כפל עשירוניים במספרים שלמים

ביחידה הזאת נלמד לכפול מספר עשירוני במספר שלם. אפשר לחשוב על כפל כעל חיבור חוזר.

## הסבר

כאשר כופלים מספר עשירוני במספר שלם, שואלים: כמה פעמים לוקחים את המספר?

לדוגמה:

```text
2.50 × 3 = 2.50 + 2.50 + 2.50 = 7.50
```

זה שימושי מאוד במחירים:

- אם חטיף עולה `3.20` ש"ח, אז 2 חטיפים עולים `6.40` ש"ח.
- אם מחברת עולה `4.50` ש"ח, אז 3 מחברות עולות `13.50` ש"ח.

## דוגמאות פתורות

דוגמה 1:

```text
0.5 × 4 = 2.0
```

כי חצי ועוד חצי ועוד חצי ועוד חצי הם שני שלמים.

דוגמה 2:

```text
1.25 × 4 = 5.00
```

דוגמה 3:

```text
2.80 × 5 = 14.00
```

## פעילות קצרה

בני טבלת מחיר:

| מחיר ליחידה | 2 יחידות | 3 יחידות | 5 יחידות |
|---|---|---|---|
| `1.50` ש"ח | | | |
| `2.40` ש"ח | | | |
| `3.25` ש"ח | | | |

מלאי את הטבלה.

## תרגול עצמי

1. פתרי כחיבור חוזר: `0.5 × 4`, `1.2 × 3`, `2.25 × 2`.
2. פתרי: `3.4 × 2`, `0.75 × 4`, `1.05 × 6`.
3. בעיה: בקבוק מים עולה `2.80` ש"ח. כמה יעלו 5 בקבוקים?
4. בדקי באומדן: האם `4.90 × 3` קרוב יותר ל-12 או ל-15?
5. כתבי מחיר למוצר וחשבי כמה יעלו 4 יחידות ממנו.

## מה חשוב לזכור?

- כפל הוא חיבור חוזר.
- בכסף, כדאי לשמור שתי ספרות אחרי הנקודה.
- אומדן עוזר לבדוק אם התשובה נשמעת הגיונית.
